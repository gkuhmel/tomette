## App Store · Description (identique sur Google Play) (1525/4000)

```text
Tomettes ist ein Action-Puzzle, inspiriert von den sechseckigen Terrakottafliesen provenzalischer Häuser.

Tausche Fliesen schräg und verbinde drei oder mehr gleiche Farben … während der Stapel steigt! Fliesen fallen nach, neue Reihen entstehen und die Ketten reißen nicht ab: ×2, ×3, ×7 …

SCHNELL GELERNT
• Eine einzige Geste: eine Fliese zur schrägen Nachbarin schieben
• Ein Tutorial direkt auf dem Spielfeld
• 4 Schwierigkeitsstufen, von Entspannt bis Extrem

IDEEN ZUM ENTDECKEN
• Rosetten: Umgib eine Fliese mit einer Farbe und gewinne die Goldfliese, die eine ganze Farbe abräumt
• Aufträge: Lege das gewünschte Muster für einen großen Bonus
• Gerissene und versiegelte Fliesen, Joker und Mörtelplatten sorgen für Abwechslung

7 ARTEN ZU SPIELEN
• Klassisch: Wie lange hältst du durch?
• Gegen die Uhr: 2 Minuten für deinen besten Punktestand
• Mosaik: so viele Rosetten wie möglich in 3 Minuten
• Express: Start auf Level 8, hier geht es schnell
• Kampagne: 30 Runden mit Ziellinie, bis zu 3 Sterne pro Runde
• Expedition: 20 Runden, ein einziges Leben und nach jeder Runde eine Karte mit Vorteil und Haken
• Duell: Tritt gegen den Computer an oder fordere online einen Freund mit einem einfachen Code heraus

AUSSERDEM
• Tägliche Missionen und ein Spielerlevel
• 48 Erfolge, Statistiken, Themen und Symbolsätze zum Freischalten
• Offline spielbar (außer dem Online-Duell)
• Ohne Werbung, ohne Konto: Deine Spiele bleiben auf deinem Handy

Die Terrakottafliesen aus Südfrankreich haben noch nie so viel Spaß gemacht.
```
