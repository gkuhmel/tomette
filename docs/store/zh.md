## App Store · Description (identique sur Google Play) (527/4000)

```text
Tomettes 是一款动作益智游戏，灵感来自普罗旺斯民居里的六边形陶土花砖。

斜向交换花砖，让 3 块或更多同色花砖连成一线……同时砖堆还在不断上升！花砖落下，新的连线形成，连锁一个接一个：×2、×3、×7……

轻松上手
• 只需一个手势：把花砖滑向斜方向的相邻位置
• 直接在棋盘上进行的新手教程
• 4 种难度，从休闲到极限

更多玩法等你发现
• 花窗：用同一种颜色围住一块花砖，赢得金花砖，可以消除整种颜色
• 订单：拼出指定图案，获得丰厚奖励
• 裂纹花砖、封印花砖、百搭和砂浆板，让对局更有变化

7 种玩法
• 经典：你能坚持多久？
• 计时赛：2 分钟冲击最高分
• 马赛克：3 分钟内拼出尽可能多的花窗
• 快车：从第 8 级开始，节奏飞快
• 闯关：30 关终点线挑战，每关最多 3 颗星
• 远征：20 关、只有一条命，每过一关选一张卡，有好处也有代价
• 对战：挑战电脑，或用一个简单的代码与好友在线对战

还有
• 每日任务与玩家等级
• 44 项成就、统计数据、可解锁的主题与图标
• 支持离线游玩（在线对战除外）
• 无广告、无需注册：你的游戏记录只保存在你的手机上

法国南部家家户户的陶土花砖，从来没有这么好玩过。
```
